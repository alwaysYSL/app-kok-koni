# Arsip dokumentasi

Folder ini menyimpan audit, rencana implementasi, dan spesifikasi historis agar jejak keputusan proyek tetap tersedia.

- `audits`: hasil peninjauan pada waktu tertentu.
- `plans`: langkah implementasi yang pernah direncanakan.
- `specs`: rancangan fitur dan perubahan terdahulu.

Checklist yang dicentang atau rekomendasi di dalam arsip bukan bukti kondisi source saat ini. Gunakan [status proyek](../project-status.md) dan [indeks dokumentasi](../README.md) sebagai titik awal.
