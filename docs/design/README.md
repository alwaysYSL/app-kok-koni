# Catatan desain

[Wireframe KOK](wireframe-kok.pdf) adalah spesifikasi ringkas awal. Implementasi telah berubah berdasarkan pembahasan lanjutan:

- Modul Anggota menampilkan kepengurusan KOK, bukan daftar gabungan atlet dan peran klub.
- Atlet, pelatih, dan official ditempatkan dalam konteks detail klub.
- Modul Cabor ditambahkan sebagai pintu masuk data cabang olahraga dan klub.
- Alur autentikasi dan kesiapan integrasi API dikembangkan setelah wireframe dibuat.

Karena itu, wireframe dipakai sebagai konteks desain awal. Source, test, status proyek, dan kontrak API aktif menjadi acuan untuk perilaku terbaru.
